# TecAssist - Frontend

Este é o frontend do sistema TecAssist, desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Engenharia de Software.

## Sobre o projeto

O TecAssist é uma aplicação web/mobile desenvolvida com Flutter de gestão para assistências técnicas.

## Tecnologias utilizadas

- Dart
- [outras libs que você usou]
