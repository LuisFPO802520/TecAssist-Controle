# Requisitos Funcionais

O sistema deve atender aos seguintes requisitos funcionais:

## RF01 - Gerenciamento de Usuários

O sistema deve permitir o cadastro, edição, consulta e exclusão de usuários, incluindo os perfis: administrador, funcionário e cliente.

## RF02 - Autenticação de Usuários

O sistema deve permitir que usuários realizem login no sistema conforme suas permissões de acesso.

## RF03 - Agendamento de Atendimentos

O sistema deve permitir o agendamento de atendimentos relacionados a serviços da assistência técnica.

## RF04 - Consulta de Agenda

O sistema deve permitir a visualização dos agendamentos em formato de lista ou calendário.

## RF05 - Controle de Estoque

O sistema deve permitir o controle de peças e equipamentos.

## RF06 - Movimentação de Estoque

O sistema deve registrar entradas e saídas de peças no estoque.

## RF07 - Registro de Serviços

O sistema deve permitir o cadastro de serviços realizados associados a clientes.

## RF08 - Histórico de Atendimentos

O sistema deve armazenar e permitir consulta do histórico completo de atendimentos de clientes.

## RF09 - Atualização de Status de Serviços

O sistema deve permitir a atualização do status dos serviços (ex: pendente, em andamento, concluído).

## RF10 - Notificações

O sistema deve enviar notificações automáticas aos clientes sobre atualizações no andamento do serviço.

## RF11 - Consulta de Clientes e Serviços

O sistema deve permitir a consulta de dados de clientes e serviços cadastrados.

## RF12 - Edição e Exclusão de Registros

O sistema deve permitir a edição e exclusão de registros de clientes, serviços e estoque.

## RF13 - Busca de Informações

O sistema deve permitir a busca de informações por nome do cliente ou serviço.

## RF14 - Registro de Observações

O sistema deve permitir o registro de observações em cada atendimento.

## RF15 - Controle de Múltiplos Atendimentos

O sistema deve permitir o gerenciamento simultâneo de múltiplos atendimentos.
