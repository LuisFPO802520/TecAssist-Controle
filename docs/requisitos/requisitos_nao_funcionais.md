# Requisitos Não Funcionais

O sistema deve atender aos seguintes requisitos não funcionais:

## RNF01 - Plataforma

O sistema deverá ser desenvolvido como um aplicativo mobile.

## RNF02 - Compatibilidade

O sistema deverá ser compatível com dispositivos Android e com versão web.

## RNF03 - Usabilidade

O sistema deverá possuir interface simples, intuitiva e de fácil utilização.

## RNF04 - Desempenho

O sistema deverá apresentar tempo de resposta rápido nas operações.

## RNF05 - Segurança

O sistema deverá garantir a segurança das informações dos usuários e dados armazenados.

## RNF06 - Persistência de Dados

O sistema deverá armazenar e manter os dados de forma consistente.

## RNF07 - Conectividade

O sistema deverá funcionar com conexão à internet.

## RNF08 - Manutenibilidade

O sistema deverá permitir fácil manutenção e atualização.

## RNF09 - Estabilidade

O sistema deverá apresentar estabilidade durante sua execução.

## RNF10 - Integridade de Dados

O sistema deverá garantir a integridade dos dados cadastrados.

## RNF11 - Boas Práticas

O sistema deverá seguir boas práticas de desenvolvimento de software.
